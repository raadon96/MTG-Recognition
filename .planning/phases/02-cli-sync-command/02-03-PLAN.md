## Phase Goal

**As a** collaborator with the repo cloned, **I want to** run a single `mtg sync` command that brings my local `data/reference/` directory into a consistent state — MobileCache rebuilt from the latest MTGJSON, missing card images downloaded, pHash index regenerated — **so that** I can go from a fresh checkout to a working recognition stack without running three separate scripts or remembering which one rebuilds what.

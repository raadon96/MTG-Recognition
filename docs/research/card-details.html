Where each detail sits, per frame and layout

Research for issue #193; notes in docs/research/card-details.md. Boxes are the production PP-OCRv5 model's text lines on 20 sampled reference images per group (read on the whole card at 2x, sideways layouts also read rotated), matched against each printing's own details. Dashed black boxes are today's two crops (NAME_ROI, COLLECTOR_INFORMATION_ROI). One text line can hold several details (e.g. "OGW*EN LIUS LASAHIDO"); each box takes the colour of its first detail. Traps

  • Year does not predict frame. 4,868 printings (4.2% of the catalog) carry the 1993 or 1997 frame in a set released after July 2003, or the 2003 frame after July 2014: The List, Masters Editions, 30th Anniversary Edition, the Remastered sets' retro cards, Secret Lair, Modern Horizons timeshifts. 2,276 Magic Online promos carry the 2015 frame with a set date of 2002. Mystery Booster 2 (2024) reprints cards in the future frame.
  • The copyright year is not the catalog's year. Scoring compares the read copyright year with setReleaseYear, the set's release year. Measured: all 20 sampled List cards print another year than the catalog's 2020 (each prints its original set's year); Secret Lair prints the year of the drop (2023-2026) against the catalog's 2019; Time Spiral Remastered prints 2020 against 2021. Older frames print a range (1993-2001).
  • Base set size is not always printed, and is not always the catalog's. Cards before Exodus (1998) print no collector number. From 2023 on, cards print the rarity then a four-digit number (C 0254) and no base set size; so do retro-frame reprints, Commander and other supplemental sets (267). Promos print their parent's number and size (PKHM 214p prints 214/285; the catalog has 214p and 1). The List prints the original set's number and size (128/169) where the catalog has HOP-128 and 5,075.
  • The printed set code is not always the catalog's. Set codes are printed only from Magic 2015 on. Promo sets print their parent's code (POGW prints OGW). The List prints the original set's code.
  • Two catalog rows for one card. Split, adventure, aftermath, flip and prepare cards have one row per face, both with the full "A // B" name, the same number and the same image (so the same pHash). Only P/T differs, and only when one face is a creature.
  • The printed name is not the catalog's name on 3,398 printings with a flavor name (Godzilla series, Secret Lair crossovers): the large name at the top is the flavor name, and the real name sits in small type below it, outside today's name crop.
  • Text the catalog doesn't hold, inside today's collector information crop: the last line of flavor or rules text, the MDFC hint bar (CR 712.3c), licensing lines (MARVEL, SQUARE ENIX, Viacom), playtest marks (CONFIDENTIAL, TEST CARD). Transform fronts print the back face's P/T in grey above their own (CR 712.2c).
  • Sideways and upside-down text. Split cards (Rooms included), battles and planes print their names sideways; aftermath prints its second half sideways; flip cards print the second name and P/T upside down. Split cards older than the 2015 frame, and planes, print their collector information sideways too. Production reads without textline orientation, so it reads none of these.
  • Old-frame P/T and collector numbers are misread. On 1997-frame cards OCR reads 2/2 as 212 or 2/12, and the collector number is glued to the copyright line (Wizards of the Coast LLC197/318, 751350 for 75/350).
  • Online-only printings are 8% of the catalog (9,409 rows): no physical card exists, yet they are candidates.

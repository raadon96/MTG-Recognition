## Phase Goal

**As a** collaborator who already has reference images on disk, **I want to** rebuild the pHash index from those images via `mtg build-index` with optional `--force` and `--workers` flags, **so that** I can refresh the perceptual hash index after manually changing the reference image set — without running the full `mtg sync` pipeline.

## Plan 02: Vertical Slice — `mtg build-index` Subcommand

<objective>

After this plan, a user with reference images already on disk can rebuild the pHash index in one command without invoking `mtg sync` or running Python directly.

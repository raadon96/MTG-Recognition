## User Setup Required

**Task 3 (Checkpoint) — GCP OAuth credentials required before Task 4 can run.**

To resume, the user must:

1. **Create GCP project + OAuth Desktop app** (one-time):
   - Go to https://console.cloud.google.com/ and create a project
   - Enable the **Google Drive API** (APIs & Services → Library → "Google Drive API" → Enable)
   - Configure OAuth consent screen: User Type = External; add your email as a Test user
   - Create credentials: APIs & Services → Credentials → Create Credentials → OAuth client ID → **Desktop app** → copy `client_id` and `client_secret`

2. **Create the Google Drive folder hierarchy** (required — auto-creation undocumented for root-based URLs):
   - In https://drive.google.com/, manually create nested folders: `My Drive / decksray / MTG-Recognition / data / test`

3. **Provide the credentials** by exporting them in the shell that will resume execution:
   ```bash
   export GDRIVE_CLIENT_ID='<paste-client-id>'
   export GDRIVE_CLIENT_SECRET='<paste-client-secret>'
   ```
   Then reply `approved`. Task 4 will read both from the environment.
